1. Executive Summary & Core Principles

NEXPAD Desktop is an open-source, ultra-low-latency virtual gamepad controller companion application developed by Sanket Parmar for Windows 10 and 11. It transforms mobile devices into virtual Xbox 360 and DualShock 4 controllers for PC games and emulators.

🛡️ Absolute Privacy Guarantee

NEXPAD Desktop does not collect, record, log, harvest, or transmit any Personally Identifiable Information (PII), telemetry data, or hardware serial numbers. The application functions 100% offline without any cloud server dependency.

2. Zero Personal Data Collection

NEXPAD Desktop operates strictly within your local machine boundaries:

  • No Personal Identifiers: We do not collect names, email addresses, phone numbers, or passwords.
  • No Telemetry or Analytics: The desktop software contains no tracking frameworks, no telemetry collectors, and no background crash uploaders.
  • No Cloud Servers: NEXPAD Desktop never communicates with any external proprietary server or database.
  • No Account Required: No login, account creation, or registration is required to use all features of the application.

3. Local Transports & Network Architecture

NEXPAD Desktop receives controller inputs from the NEXPAD mobile client across three local communication channels:

A. Local Wi-Fi (UDP Protocol)

NEXPAD Desktop binds to local network UDP ports (e.g., 26760 for CemuHook DSU motion aiming and 26761 for gamepad reports) strictly within your private Local Area Network (LAN). Packets are never forwarded outside your home network or across the public internet.

B. Physical USB Connection (AOA 2.0 & ADB)

When connected via USB cable, gamepad inputs are transferred directly across physical copper wires via standard Android Open Accessory or ADB port forwarding. No network interface is used.

C. Bluetooth RFCOMM

NEXPAD Desktop pairs directly with your mobile device using Windows Bluetooth RFCOMM serial communication.

4. Driver Emulation & System Safety

To deliver console-grade compatibility with Windows games, NEXPAD Desktop interfaces with the open-source ViGEmBus (Virtual Gamepad Emulation Framework) driver:

  • Standard Input Reports: Inputs are translated 1:1 into genuine XUSB (Xbox 360) and DS4 (DualShock 4) reports.
  • No Macros or Cheats: The software does not inject into game processes, does not tamper with memory, and includes no automated scripts or aimbots.
  • Safe Operation: The driver communicates only with the Windows operating system input subsystem.

5. Windows System Capabilities & Permissions

Capability / Resource Technical Purpose Data Handling & Scope
runFullTrust Allows native Win32 execution for low-latency UDP socket networking, USB device communication, and ViGEm driver interfacing. Operates strictly on the local PC. Zero data is exported.
Local Network Access Enables receiving low-latency gamepad UDP packets from the mobile controller client on your Wi-Fi network. Restricted to private LAN. No outgoing public internet traffic.
Local Preferences Stores user UI preferences (selected theme, port numbers, sensitivity curves) in the local application data directory. Stored strictly on your local disk. Never synced to external clouds.
